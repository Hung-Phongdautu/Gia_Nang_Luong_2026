# Gia_Nang_Luong_2026
Giá năng lượng 2026

PWA/web app tra cứu giá xăng dầu Petrolimex và giá điện dùng cho ca máy.

Chạy trên GitHub Pages

1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file trong thư mục này vào nhánh main.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch.
5. Chọn nhánh main và thư mục / (root).
6. Lưu lại. GitHub sẽ cấp URL dạng https://<username>.github.io/<repo>/.

App không cần file Excel khi chạy; CSDL đã được nhúng trong index.html.
